# OLC Liberation APR
Ohio Liberation Command's fork of APR's 0.96.8 KP Liberation Fork.

This fork is a modified version of APR's fork, built specifically for our community.

I Do not recommend using this for your own Liberation campaigns, as it has numerous changes built specifically to work with our community, on our server, such as minimum player limits for objective capture, and a role-based limited arsenal system.
